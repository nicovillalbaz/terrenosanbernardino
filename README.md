Luces. una landing page inmobiliaria profesional para la venta de un terreno en Google Pages, con un diseño elegante y potente que muestre todas las características del terreno a la venta.

## Propósito
Esta landing page está diseñada para promocionar un terreno en venta con un estilo profesional y atractivo que capte la atención de los compradores interesados. El objetivo es presentar el terreno de manera atractiva, mostrar sus características principales, proporcionar información de ubicación y contacto, y facilitar la comunicación directa con el propietario a través de WhatsApp.

- **Cache strategy**: Configurar headers de cache adecuados

## Activación del servicio PWA

### Para instalar como PWA
1. Abrir la página en navegador compatible (Chrome, Firefox, Edge)
2. Click en el ícono de instalación (⌄) en la barra de direcciones
3. Opcionalmente, click en "Añadir a pantalla de inicio"
4. Aceptar para instalar como aplicación nativa
5. Ahora tendrás una experiencia PWA con:
   - Offline capability
   - Instalación en home screen
   - Notification support
   - Splash screen en inicio
